# kakeibo（家計簿）

ブラウザだけで動く、自分用の収支管理アプリです。サーバーやアカウントは要りません。

- HTML / CSS / バニラ JavaScript だけで動きます（ビルド不要・外部ライブラリなし）
- `index.html` をブラウザで開くだけで使えます。GitHub Pages で公開すれば、スマホのホーム画面に追加してオフラインでも使えます（PWA）

> [!IMPORTANT]
> **データはブラウザの中（localStorage / IndexedDB）にしか保存されません。**
> サーバーには送られないので、ほかの端末とは同期されません。ブラウザのデータ消去、シークレットウィンドウ、端末の故障・買い替えで消えます。
> **「設定 → データ管理 → バックアップを保存」で、定期的に JSON バックアップを取ってください。**
> （同じ PC でも、`file://` で開いた場合と GitHub Pages で開いた場合ではデータの保存場所が別になります。）

## 機能

### 1. 入力・記録
- 収入・支出・振替の登録（日付、金額、カテゴリ、お店・相手、メモ、支払い方法、口座）
- 入力は画面を移らずにシートで開きます。「今日／昨日」ボタン、前回の口座とカテゴリを記憶、「保存して続ける」に対応
- **テンプレート**：ホームのボタンをワンタップで、今日の日付で記録（間違えたら「元に戻す」）
- **定期**：家賃・サブスク・給与などを毎月自動で登録（31日指定は月末に丸めます。うるう年に対応）
- **分割払い**：総額と回数から毎月に振り分け（端数は1回目に加算）、全回分を「予定」として登録
- **タグ**：`#旅行` のように付けると、カテゴリをまたいで集計できます
- **レシート画像**：長辺 1280px に縮小し、JPEG に圧縮して IndexedDB に保存

### 2. 口座・資産
- 財布・銀行・クレジットカード・電子マネーごとの残高
- 口座間の振替（ATM 引き出し、チャージ、カードの引き落とし）。振替は収支の集計に含めません
- クレジットカードの締め日・支払日から、引き落とし日と金額を予測（土日は翌月曜にずらします）。引き落とし口座の残高不足も警告
- 資産推移グラフ（過去12か月＋予測）、貯金目標と達成率

### 3. 予算
- カテゴリ別の月予算（変更はその月以降に適用され、過去の月は変わりません）
- 使いすぎ警告：80% で黄色の「注意」、100% で赤の「超過」（色だけでなく文字とアイコンでも表示）
- 今月あと1日いくら使えるか（予定と、まだ登録されていない今月の固定費を差し引いて計算）
- 余った予算の翌月繰り越し（ON/OFF。ON にした月から計算し、超過分は繰り越しません）

### 4. 分析・グラフ
- 月別収支の推移（棒＋折れ線）、カテゴリ別ドーナツグラフ
- 前月比・前年同月比、カレンダー（日ごとの支出のヒートマップ）
- 支出ランキング（カテゴリ別・お店／メモ別）、タグ別集計
- 月末残高の将来予測（4か月先まで）、年間レポート（印刷可）
- グラフはすべて「数値で見る」の表でも確認できます

### 5. 検索・整理
- キーワード・期間・金額・カテゴリ・タグ・口座・種類で絞り込み、並べ替え
- まとめて編集（カテゴリ・口座・タグ）・まとめて削除、絞り込んだ結果だけ CSV 書き出し
- カテゴリの追加・編集・並べ替え（アイコンと色を選べます）

### 6. データ管理
- CSV の書き出し・読み込み（BOM 付き UTF-8 なので Excel で文字化けしません。読み込みは UTF-8 と Shift_JIS に対応）
- JSON でのバックアップと復元（レシート画像を含めるか選べます）
- 元に戻す（Undo）：削除・編集・一括操作・読み込み・復元などを直前から最大20回まで戻せます（トーストのボタン、`Ctrl+Z`、設定画面）。ページを再読み込みすると履歴は消えます
- データには `schemaVersion` があり、将来の形式変更時は自動で移行します（移行前のデータは退避します）

### 7. 使いやすさ
- スマホ対応（スマホでは下部タブ、PC では左サイドバー）
- ダークモード（OS の設定に合わせる／手動で切り替え）
- PWA（ホーム画面に追加、オフライン動作）
- 簡易パスコードロック（ソルト付きで繰り返しハッシュ化して保存。5分以上ほかのアプリに切り替えていたら再ロック）。**のぞき見防止用の簡易ロックで、データ自体は暗号化されていません**
- 入力リマインダー（Notification API。通知が許可されていない場合や、閉じている間に時刻を過ぎた場合はアプリ内のバナーで知らせます）
- キーボード：`N` で記録、`Ctrl+Z` で元に戻す

### 8. 続ける仕組み
- 連続入力日数（定期の自動登録は数えません）と最長記録
- バッジ（はじめの一歩、3/7/30/100日連続、記録100件、予算達成、黒字の月、3か月連続黒字、節約上手、目標達成）

## 使い方

1. このリポジトリをダウンロード（または clone）して、`index.html` をブラウザで開きます
2. 初回は「空の状態で始める」か「サンプルデータを入れて試す」を選びます（標準のカテゴリと口座が用意されます）
3. 「＋ 記録する」（スマホは下の ＋ ボタン、PC は `N` キー）から記録します
4. 「口座・資産」で各口座の今の残高（記録を始める前の残高）を入れておくと、残高や資産推移が正しくなります

> `file://` で開いた場合、Service Worker（オフライン用のキャッシュ）は使えません。それ以外の機能は使えます。

## GitHub Pages で公開する

1. GitHub のリポジトリで **Settings → Pages** を開く
2. **Build and deployment** の Source を「Deploy from a branch」、Branch を `main` / `/ (root)` にして Save
3. 数分後に `https://<ユーザー名>.github.io/kakeibo/` で開けます
4. スマホでは、ブラウザのメニューから「ホーム画面に追加」するとアプリのように使えます（オフラインでも動きます）

> [!NOTE]
> 無料プランでは、GitHub Pages を private リポジトリで使えません。public にするか、有料プランが必要です。public にしても、**公開されるのはアプリのコードだけ**です。家計のデータは各自のブラウザの中にあるので、公開されません。

アプリを更新したときは、`sw.js` の `VERSION` を上げてください。利用者の画面に「新しいバージョンがあります　更新する」と出て、押すと新しい版に切り替わります。

## ファイル構成

```
index.html              画面の骨組み
css/style.css           見た目（ライト／ダーク）
js/util.js              エスケープ、金額・日付、SHA-256、CSV
js/idb.js               IndexedDB の小さなラッパー
js/store.js             データ層（保存、schemaVersion とマイグレーション、Undo、初期データ）
js/calc.js              計算（集計、残高、予算と繰り越し、予測、定期・分割、バッジ）
js/receipts.js          レシート画像の圧縮と保存
js/io.js                CSV / JSON の入出力
js/charts.js            SVG グラフ
js/ui.js                ルーター、モーダル、トースト、共通部品
js/views/*.js           画面ごとの処理
js/app.js               起動処理、ロック、リマインダー、PWA
sw.js, manifest.webmanifest, icons/   PWA
tests/e2e.js            動作確認スクリプト（Playwright）
docs/design.md          設計メモ
docs/review-notes.md    レビューの記録
```

```sh
python3 -m http.server 8765 &
npm i -D playwright   # 未導入なら
node tests/e2e.js /tmp/kakeibo-out
```

計算の単体確認（分割の端数、月末・うるう年、繰り越し、クレカ予測など）、主要な流れ（登録→集計→グラフ→予算警告→CSV/JSON の往復→Undo）、スマホ幅の横スクロール、3万件での表示速度を確かめます。
